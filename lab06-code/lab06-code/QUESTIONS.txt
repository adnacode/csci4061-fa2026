CODE Complete square_root.c
===============================

  Complete the code in 'square_root.c'. This is a very small C extension for
  Python with just one function, 'square_root'. This function accepts as input
  a Python list of integers, computes the square root of each integer, and
  returns a new list of floating-point numbers with the results. Expressed as
  pseudocode:

      output_list[i] = sqrt(input_list[i])

  The function only succeeds if every element in the input list is a positive
  number. If the function encounters a negative number, it should indicate a
  failure by raising a 'ValueError' with the message "Cannot compute square
  root of negative value".

  The 'square_root' function should take the following steps:

  1. Parse the argument passed in from Python and report an error if it is not
     a Python list.
  2. Create a new list to hold the square root results.
  3. Iterate over each value in the input list and compute its square root.
     Store the result in the output list.
  4. If a negative value is seen, report a 'ValueError' back to Python. Don't
     forget any necessary cleanup.
  5. Return the list of square root values.

  We have already provided a simple Python program in 'square_root_main.py' to
  exercise this function for you. Here is the expected output of the test
  program:

  ,----
  | > python3 square_root_main.py
  | List 1:
  | 2.000
  | 2.828
  | 3.873
  | 4.000
  | 4.796
  | 6.481
  | 10.392
  |
  | List 2:
  | Could not compute square roots due to invalid list element
  `----
