CODE Complete square_numbers.c
===============================

  Complete the code in 'square_numbers.c'. The goal of this code is compute the
  square of each element of 'numbers', the global array declared at the top of
  the file. Rather than compute the results sequentially, they will be computed
  in parallel by a fixed-size group of worker processes. The number of workers
  is specified as a command-line argument.

  The code attempts to print out the squared values at the end of its
  execution. Your program should produce the correct results regardless of the
  number of workers chosen by the user. You should also aim to divide up the
  work (chunks of the 'numbers' array) as evenly as possible among the workers.

  Here's the rough sequence of steps your code should follow:

  1. Fork the specified number of worker processes, ensuring that they all have
     access to a single shared memory segment to hold the results (squared
     values), also accessible from the original parent process.
  2. Each child computes the square of each element in its assigned chunk of
     the 'numbers' array. The chunks should be disjoint, meaning no workers try
     to square any of the same elements.
  3. In the parent, print out the squared values once the data is ready.
